## 风险

| 风险 | 应对 |
|---|---|
| 没有可用 Key | 本地算法已完备，云端作为加分项；文档写清两条路径 |
| 演示素材的可信度 | ✅ 已换为真实公开材料，链接可核对；正文是中文整理稿，答辩时说明「引用以原文为准」 |
| 图谱在无 GPU 环境卡顿 | 已降级（Canvas 前置方案的历史经验），可减粒子数量 |
| 时间不足 | 优先保证 `/kb → 图谱 → 缺口` 三条主线的演示质量 |
