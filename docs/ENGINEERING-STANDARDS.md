## 3. UI 组件库

### 标准
| 编号 | 规则 |
|---|---|
| U1 | 原语覆盖：Button / Input / Badge / Dialog / Tooltip / Toast / Tabs |
| U2 | 变体集中在组件内用 `Record<Variant, string>` 定义，不散落在调用处 |
| U3 | 原语不含业务语义（`TraceCard` 不是原语） |
| U4 | 与生态的关系要**明确决策**并写进文档，不能"既想用 shadcn 又手写" |

### 自检
| 项 | 结果 | 说明 |
|---|---|---|
| U1 | ⚠️ 4/7 | Button / Badge / StatusIcon / Card；缺 Input / Dialog / Tooltip / Toast / Tabs |
| U2 | ✅ | 变体表内聚 |
| U3 | ✅ | `ui/` 下无业务词 |
| U4 | ❌ | 备赛文档推荐 shadcn，当前为手写 |

### 决策（写入标准，别再摇摆）
> **保持自建，只按需引入 Radix 无头组件。**
> 理由：shadcn 会带进 30+ 文件与大量未用变体，22 天内维护成本高；现有视觉体系已成型（15 色 / 5 档字号），此时换库等于重做。只在需要 Dialog / Tooltip / Toast 时引入对应 Radix 包（每个约 20KB，且不带样式）。

## 4. 目录结构

### 标准
| 编号 | 规则 |
|---|---|
| D1 | 分层：`app`（路由，薄）→ `features`（业务）→ `components`（展示）→ `lib`（领域/工具） |
| D2 | `lib` 内单一职责：domain / agent / state / config **必须分包** |
| D3 | 依赖单向，无循环 |
| D4 | 模块有统一入口（`index.ts`），跨层只走入口 |

### 现状
```
app/            路由 + API 占位           ✅ 薄
components/
  shell/ chat/ trace/ ui/                 ✅ 按域划分
lib/
  types.ts       领域模型                ┐
  mock-agent.ts  引擎 + 剧本 + 演示数据   ├ 5 种职责挤在一层
  store.ts       状态                    │
  tools.ts       配置                    │
  utils.ts       工具函数                ┘
  hooks.ts       状态入口（新增）         ✅
```

| 项 | 结果 |
|---|---|
| D1 | ⚠️ 无 `features`，业务（剧本）落在 `lib` |
| D2 | ❌ 5 职责混层 |
| D3 | ✅ 无环 |
| D4 | ❌ 无 barrel |

**目标结构**
```
lib/
  domain/   types.ts + 运行状态机（纯函数，无 React）
  agent/    engine.ts（脚本/SSE）+ tools.ts
  state/    store.ts
  utils/    format.ts + cn.ts
hooks/      useAgentRun / useSession（从 lib/hooks.ts 迁出）
```

## 13. 决策补充（v2，修正本文档早前的判断）

| 早前判断 | 修正 | 原因 |
|---|---|---|
| D4/M4「无 barrel」记为缺陷 | **不算缺陷**：只给 `components/ui` 建 barrel，业务目录不建 | 业务 barrel 会带来循环依赖、client/server 边界模糊、大范围重编译 |
| 未记录字号档位 | v1 规范误写了不存在的 `text-ui` | 实际档位为 10/11/12/13/16px（3xs/2xs/xs/sm/lg） |
| 未记录圆角债务 | `rounded-2xl` 1 处待收敛到 `xl` | 定义 4 档，实际使用 5 档（+full 形状） |
| M1 修复方式描述为"组件不 import store" | 准确表述：组件经 `lib/hooks.ts` 的语义 hook 访问，hook 内部才接触 store | 换状态库只改一个文件 |
| 「原始颜色」零容忍 | 改为「禁止裸 hex」：允许 white/black 透明度（Aurora 基础色阶），色值必须来自 `theme.ts` 或 CSS 变量 | `/kb` 采用 Aurora 视觉，白色透明度就是它的色阶；裸 hex 才是真正的失控信号。metadata 的 `themeColor` 单独豁免 |
