# 演示视频脚本（6 分 30 秒）

> 目标：让评委在 3 分钟内理解**这个产品解决什么问题**，在 6 分钟内相信**它真的做出来了**。
> 原则：少讲技术，多讲取舍；每个功能都回答"为什么要有它"。

---

## 录制前 15 分钟准备

### 1. 数据状态

```
① 打开 /kb/settings → 打开「显示恢复演示数据」开关
② 回工作台 → 侧边栏点「恢复演示数据」→ 回到干净 8 条
③ 进「关联」→ 点「云端重算」→ 等 15 秒（重要！否则冲突页是空的）
④ 确认「冲突」有 1 条待处理
```

> 录制时**不要**现点云端重算——等 20 秒的空白会让视频很难看。

### 2. 环境

```
□ 浏览器窗口 1440×900（或 1920×1080，录 1080p）
□ 缩放 100%，深色模式
□ 隐藏书签栏（Ctrl+Shift+B）
□ 关闭通知、微信、其他标签页
□ 录屏软件：OBS / 系统自带，帧率 30，分辨率与原窗口一致
```

### 3. 模型确认

`/kb/settings` → 「测试连接」看到绿字即可。
主模型 `deepseek-flash` 本身支持图片，**「视觉模型」三栏留空**，不用另配。

### 4. 试录一句

先录 10 秒念一遍开场，回放听一下：**语速是否偏快**。中文口播每秒约 4–5 字，脚本已按此估算。

## 正片

### 00:00–00:35　开场：一个自己的习惯

| | |
|---|---|
| **画面** | 落地页（星云缓慢流动），不做任何操作 |
| **操作** | 无 |
| **口播** | 我在短视频软件里收藏了很多觉得有用的视频。但它们进了收藏夹，就再没打开过。后来我会定期翻「我的收藏」，但收效甚微。 |
| **字幕** | 收藏 = 我已经获得了？（打在画面下方） |

> **导演提示**：这段用**最平静的语气**。不要一上来就说"我做了个 AI 产品"。

---

### 00:35–01:05　问题抽象

| | |
|---|---|
| **画面** | 落地页向下滚动，露出三行主张 |
| **操作** | 缓慢滚动，停住 |
| **口播** | 问题不在找不到，而在收藏这个动作本身给了「我已经获得了」的错觉。真正缺的是后面那一步：存完之后，有没有真的想清楚。 |
| **字幕** | 存 → 看了不写 → 写了不判断 |

---

### 01:05–01:25　一句话定位

| | |
|---|---|
| **画面** | 停在落地页标题区，鼠标轻移到「进入知识库」 |
| **操作** | 说完整句后再点 |
| **口播** | 所以我做了织识 Loom。一句话：AI 负责让你看清，不负责替你想清楚。 |
| **字幕** | **AI 负责让你看清，不负责替你想清楚** |

> 这是全片最重要的一句话，**说完停半秒**再点进去。

---

### 01:25–02:10　它怎么"逼你输出"：收件箱

| | |
|---|---|
| **画面** | 进入 /kb，默认在知识库。点左侧「收件箱」 |
| **操作** | 点「收件箱」→ 停留 → 点「让模型帮我想 · 可追问」 |
| **口播** | 这个知识库有个规矩：存素材必须写一句「为什么存它」。不写，就躺在收件箱里，橙色角标一直提醒你。想不出来可以点「让模型帮我想」，但它只给候选，必须你自己选一句或者改一句。 |
| **字幕** | 收件箱 1 条未消化　·　模型只给候选，不替你决定 |

> 弹窗里**不要真的点采用**，停在三个建议上即可，避免改坏数据。

---

### 02:10–02:50　写之前先体检：缺口

| | |
|---|---|
| **画面** | 点「缺口」，输入一句话后点检测 |
| **操作** | 输入：`写一篇关于 AI Agent 落地现状的综述，说明哪些项目真的跑通了` |
| **口播** | 写作之前先查缺口。它告诉你这三个方向没有证据：落地现状、跑通、原因。覆盖率只有百分之十几。这不是打分，是缺口清单——写着写着发现没材料，比写完才发现好。 |
| **字幕** | 覆盖率 16%　·　缺的不是字，是证据 |

> 数字以实际显示为准，念之前看一眼。

---

### 02:50–03:30　看得见的关系：图谱

| | |
|---|---|
| **画面** | 点「关联」，拖动旋转一下 |
| **操作** | 拖拽旋转 2 秒 → 停止 → 鼠标悬停右侧一条关联卡片 |
| **口播** | 每一根线都是一条真实关系。拖拽可以转，点节点能打开原文。右边这条是「最值得看的关联」，悬停它，图上只亮这一对。 |
| **字幕** | 本地算法算词面，云端模型判语义 |

> 拖拽那 2 秒后期可以加速到 1 秒，别让观众等。

---

### 03:30–04:40　核心差异：冲突必须由你判断

| | |
|---|---|
| **画面** | 点「冲突」，出现一条待处理 |
| **操作** | 停留 1 秒 → 点「让模型说清分歧，并可追问」→ 等结果 → 关掉弹窗 → 点「采纳前者」→ 输入一句理由 → 确认 |
| **口播** | 这两条材料是矛盾的：一篇说 Copilot 让任务快了一半多，另一篇说资深开发者用了 AI 反而慢了百分之十九。模型标出来了，但它不替你决定。我点一下，它会说清这两个实验到底在争什么。现在我来判断——我采纳 METR，因为它的场景更接近真实工作。 |
| **字幕** | 不做判断，简报就无法生成 |

> 这是全片高潮，**节奏放慢**。输入理由时可以只打一半（`因为 METR 测的是真实仓库`），后期加速打字过程。

---

### 04:40–05:00　反方证据不删，进文件夹

| | |
|---|---|
| **画面** | 点「文件夹」 |
| **操作** | 停留 2 秒 → 点其中一条看详情 |
| **口播** | 被取代的那条没有被删掉，而是收进文件夹，随时能翻回来对照。详情页里能直接跳到对方那条。 |
| **字幕** | 不做删除，做归档 |

---

### 05:00–05:50　问答：先给证据，再问要不要解释

| | |
|---|---|
| **画面** | 点「问答」，输入问题 |
| **操作** | 输入：`大学应该学 AI 学什么？` → 点「检索」→ 点「让模型补充背景」→ 等结果 |
| **口播** | 问一个库里没有的问题。它先说：库里没有相关内容。但它不就此结束——我点「让模型补充背景」，它会给一段自己的知识，而且明确标出来：这部分不在你的素材里。 |
| **字幕** | 有出处的和没出处的，分开放 |

> 这里最能体现「不缝合」。**手指不要挡住琥珀色那块**，那是重点。

---

### 05:50–06:20　从发现缺口到补上

| | |
|---|---|
| **画面** | 继续停留在问答页，往下滚一点 |
| **操作** | 点「让模型找几篇能补上的材料」→ 等 3 条建议 → 点其中一条的「抓取正文并加入知识库」 |
| **口播** | 指出缺口还不够，得能补上。它推荐几篇真实存在的材料，加不加由我决定。点一下，正文抓下来，直接进知识库——而且自动带着「为什么存它」。 |
| **字幕** | 推荐 ≠ 入库，你说了算 |

---

### 06:20–06:30　收尾

| | |
|---|---|
| **画面** | 回到知识库列表（9 条素材），鼠标不动 |
| **操作** | 无 |
| **口播** | 它不替你收藏，也不替你想清楚。它只是让你看见：你缺什么，你信什么。 |
| **字幕** | 织识 Loom　http://8.163.104.134 |

> 结尾**不要**念技术栈。停在最后一句话上，字幕落下即可。

**可选 8 秒**：如果想让评委看到"考虑过运维"，在收尾前插一个镜头——
打开 `/kb/metrics`，说一句「服务端只记延迟、成功率、错误分布，不记用户内容」，然后切回知识库。

## 如果只能录 3 分钟（备用版）

砍掉：开场（换成 10 秒）、缺口、文件夹。

保留：**定位句 → 冲突判断 → 问答两段式**。这三个是产品最不可替代的部分。

## 常见翻车点

| 问题 | 预防 |
|---|---|
| 冲突页是空的 | 录制前先跑一次「云端重算」 |
| 点云端重算卡 20 秒 | 提前算好，录的时候别再点 |
| 模型返回失败 | 录前测 3 次，确认额度充足 |
| 素材数量不是 8 | 先「恢复演示数据」 |
| 画面里有其他标签页 | 单独开一个窗口 |
| 口播太赶 | 每段之间留 1 秒空白，后期好剪 |
| 详情抽屉打开后回不去 | 手机端是全屏抽屉，点右上角 × 关闭 |
| 想演示"出错怎么办" | 不建议现场造错；错误条带「复制」，可单独截一张图放进文档 |
