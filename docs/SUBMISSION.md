## 三、作品简介（约 120 字，可直接用）

```
织识 Loom 是一个会「逼你输出」的个人知识库。收藏不等于学会——它要求你为每条素材写一句为什么存，
写不出来就进不了库；写作前先查证据缺口；素材之间矛盾时，模型标出来但不替你决定，
必须自己做出判断才能收口。回答分「库中依据」与「库外补充」两段，前者每句带出处。
数据只存浏览器，云端能力可降级，断网时检索、缺口、简报、图谱照常可用。
```

## 四、技术栈（表单要求列出时）

```
前端：Next.js 15（App Router）+ React 19 + TypeScript strict + Tailwind v4
状态：Zustand（localStorage 持久化）
3D：three.js（自定义着色器，按需加载）
文档解析：pdfjs-dist（浏览器端）+ unpdf（服务端兜底）
模型：OpenAI 兼容端点（默认 DeepSeek-V4.1-Flash，文本 + 图片）
部署：阿里云轻量服务器，Node 22 + pm2
```
